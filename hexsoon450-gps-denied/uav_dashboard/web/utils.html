MAV CONSOLE COMMANDS

Commands available in the MAV Command Console on the Dashboard and Flight Tests pages.

COMMAND SYNTAX DESCRIPTION
arm arm Arms the vehicle
disarm disarm Disarms the vehicle
mode mode <MODE> Sets MAVROS flight mode. E.g. mode GUIDED, mode LOITER, mode LAND, mode STABILIZE
takeoff takeoff <alt_m> Takeoff to altitude in metres. E.g. takeoff 2.5
land land Commands the vehicle to land at the current position
move move <x> <y> <z> Publishes a local ENU setpoint. E.g. move 5 0 2
move (yaw) move <x> <y> <z> <yaw> Move to position with heading in degrees. E.g. move 5 0 2 90
help help Prints this command list to the console

FLIGHT TEST COMMANDS

Commands sent by the Flight Tests page over WebSocket. Can also be typed into any MAV console.

COMMAND SYNTAX DESCRIPTION
quick_land quick_land:<alt_m> Test 1 — Arm → takeoff to alt_m → land. E.g. quick_land:2.5
hover hover:<sec>:<alt_m> Test 2 — Arm → takeoff → hover for sec seconds → land. E.g. hover:30:3
move_return move_return:<alt_m>:<dist_m> Test 3 — Arm → takeoff → fly dist_m forward (+X ENU) → return → land. E.g. move_return:2:10
search search:<type>:<alt_m>:<w_m>:<h_m>:<lane_m>:<corner>:<end_behavior>:<rover_id> Full Search Mission — Arm → takeoff → fly search pattern covering width×height area from a starting corner, searching for ArUco marker. Types: spiral, lawnmower, sar. Corners: bl, br, tl, tr. End Behaviors: land_target, land_rover. E.g. search:lawnmower:2:10:10:1.0:tl:land_target:0
preview_search preview_search:<type>:<alt_m>:<w_m>:<h_m>:<lane_m>:<corner>:<end_behavior>:<rover_id> Generate and preview the search pattern without taking off.
abort abort Abort any running flight test and command an immediate land

HTTP REST API

HTTP endpoints served on port 8000. All responses include Access-Control-Allow-Origin: *.

ENDPOINTMETHODRESPONSEDESCRIPTION
/api/map GET image/png or application/json Latest RTAB-Map occupancy grid as a PNG image.
Color: white = free, black = occupied, gray = unknown.
Map metadata in headers: X-Map-Resolution, X-Map-Origin-X, X-Map-Origin-Y, X-Map-Width, X-Map-Height.
Returns 503 JSON if no map received yet. Falls back to JSON if cv2 unavailable.
/api/aruco_tags GET application/json All ArUco tags detected since node start.
{
  "tags": [
    {
      "id": 42,
      "x": 1.83,        // ENU local frame (m)
      "y": -0.47,
      "ts": 1744742310.214,
      "map_x": 3.21,    // metres from map origin
      "map_y": 2.85,
      "px": 64.2,       // pixel in /api/map PNG
      "py": 117.5
    }
  ]
}
map_x/y/px/py omitted if no map received yet.
/api/system GET application/json Host system info: hostname, kernel, uptime, load, RAM, disk, CPU, network interfaces, gateway reachability, ROS node and topic counts.
/api/logs/runs GET application/json List of past mission run log files from ~/.ros/uav_logs/runs/. Each entry includes id, name, date, time, txt_url, jsonl_url, video_url.
/logs/<path> GET text/plain or video/mp4 Serves .txt, .jsonl, or .mp4 files from ~/.ros/uav_logs/. Path traversal is blocked.

WEBSOCKET EVENTS — INBOUND (client → server)

TYPEDATADESCRIPTION
command { data: "arm" } MAV console command string. See MAV Console Commands table above.
flight_test { data: "search:spiral:3:5:5:1:bl:land_target:0:42" } Flight test command string. Forwarded directly to /flight_test/command. See Flight Test Commands table above.
ugv_received {} Mission Control only. Send after receiving found_aruco_tag to confirm the UGV has acknowledged the target position. The UAV will then leave the hover, return home, and land on the rover if its ArUco tag is acquired en-route.
