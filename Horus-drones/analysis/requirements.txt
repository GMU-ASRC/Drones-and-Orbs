# Laptop-side analysis only -- do NOT install these on the Pi.
# The flight code (main/) adds no new dependencies beyond what the Pi already
# has (picamera2, opencv, numpy, pymavlink); everything it logs is read from
# /proc and /sys directly.
opencv-python
numpy
matplotlib        # optional: without it you still get report.md + annotated.mp4

#   sudo apt install ffmpeg      /      sudo pacman -S ffmpeg

# falls back to reading the raw stream, which works but reports no frame rate.
