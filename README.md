# Drones & Orbs

development supporting the implementation of **emergent autonomous behaviours** across a range of aerial and ground-based platforms.

---

## Repository Structure

```
/
├── hexsoon450-gps-denied/   # Working RDC code for the Hexsoon 450 in GPS-denied environments
└── ...                      # Additional platform folders to follow
```

### `hexsoon450-gps-denied/`
Contains all working code from RDC for operating the **Hexsoon 450** drone in GPS-denied conditions. This serves as a reference implementation for localisation-agnostic autonomy.

---

## Getting Started

Refer to the `README` inside each platform folder for setup instructions, dependencies, and hardware requirements specific to that platform.

---

## Contributing

When adding a new platform or behaviour module, create a dedicated folder with its own `README` describing the hardware, software dependencies, and any known limitations.
